# نجوم الرياضيات | Math Stars

منصة تدريب تفاعلية في الرياضيات لطالبات **الصف الثاني المتوسط** في **المتوسطة السابعة والخمسون**، مبنية على مجالات دراسة **TIMSS 2027** للصف الثامن، في برنامج مدته **20 أسبوعًا**.

الشعار: أتعلم، أتحدى، أتقدم، وأتألق.

تصميم: Research by Eman

## الدروس المرئية: ما الذي تفعله الأداة بالضبط

| المرحلة | الطريقة | التكلفة |
|---|---|---|
| رفع صورة الصفحة أو ملف PDF | تخزين خاص في Supabase | مجاني |
| استخراج النص | PDF: مكتبة pdf.js. الصور: Tesseract.js (التعرف الضوئي على العربية) داخل المتصفح | مجاني |
| مراجعة النص وملخص المفهوم | المعلمة | — |
| إعداد السيناريو | يدويًا من 7 قوالب، أو اقتراح آلي اختياري عبر Google Gemini | مجاني (الطبقة المجانية من Gemini، بحدود استخدام) |
| المشاهد المتحركة | **رسوم متحركة برمجية** (SVG + Framer Motion) تُعرض داخل المنصة | مجاني |
| التعليق الصوتي | تسجيل بصوت المعلمة من المتصفح لكل مشهد، مع نص مكتوب أسفل المشهد | مجاني |
| المعاينة والتعديل والاعتماد والنشر | داخل المنصة؛ أي تعديل بعد النشر يعيد الدرس إلى المراجعة | — |

**ما ليس في الأداة:** لا يوجد توليد فيديو بالذكاء الاصطناعي (مثل Veo أو Runway)، لأن هذه الخدمات مدفوعة وغير متاحة في الطبقة المجانية. ولا يوجد صوت آلي مولّد؛ التعليق بصوت المعلمة. وتصدير الدرس إلى ملف MP4 غير متاح في هذه النسخة.

القوالب: عنوان، دورة مراحل (مثل دورة الماء)، خطوات متتابعة، خط الأعداد، الميزان للمعادلات، شبكة المئة للنسب المئوية، سؤال توقف.

**ملاحظة على Gemini:** الطبقة المجانية تسمح لـ Google باستخدام المدخلات لتحسين منتجاتها. لا تُرسل إلى الخدمة إلا صفحة الكتاب ونصها، ولا تُرسل أي بيانات للطالبات. وإذا تُرك `GEMINI_API_KEY` فارغًا لا يظهر زر الاقتراح.

## التشغيل والنشر

### 1) قاعدة البيانات (Supabase)
1. أنشئي مشروعًا في [supabase.com](https://supabase.com) (الخطة المجانية تكفي للبداية).
2. من **SQL Editor** شغّلي الملفات بالترتيب:
   - `supabase/migrations/0001_schema.sql`
   - `supabase/migrations/0002_security.sql`
   - `supabase/migrations/0003_reference_data.sql`
   - `supabase/migrations/0004_library.sql` (في تنفيذ مستقل؛ لأنه يضيف قيمة جديدة لنوع بيانات)
   - `supabase/migrations/0005_library_content.sql`
   - `supabase/migrations/0006_library_files_official.sql`
3. للتجربة فقط: `supabase/demo/seed_demo.sql` (3 مهارات و12 سؤالًا تجريبيًا مُعلّمة `is_demo`).

### 2) متغيرات البيئة
انسخي `.env.example` إلى `.env.local` واملئي القيم. القيمتان `STUDENT_SESSION_SECRET` و`STUDENT_CODE_PEPPER` تُولّدان بالأمر `openssl rand -hex 32`.
**تنبيه:** إذا تغيّر `STUDENT_CODE_PEPPER` بعد إصدار الرموز بطلت كل رموز الطالبات.

### 3) الحسابات
```bash
npm install
npm run create-staff -- --email ... --name "صالحة الأسمري" --role teacher
npm run create-staff -- --email ... --name "أمل القرني" --role teacher
npm run create-staff -- --email ... --name "الإدارة" --role admin
```
ثم تدخل الإدارة وتنشئ الفصول وتربطها بالمعلمتين من صفحة «الطالبات والفصول»، وتضيف المعلمة طالباتها فيظهر رمز كل طالبة مرة واحدة.

### 4) التشغيل المحلي
```bash
npm run dev
```

### 5) GitHub وVercel
1. ارفعي المجلد إلى مستودع على GitHub (ملف `.gitignore` يستبعد `.env` وملفات Excel/CSV حتى لا تُرفع بيانات الطالبات).
2. في Vercel: **Import Project**، ثم أضيفي متغيرات البيئة نفسها في **Settings → Environment Variables**.
3. `SUPABASE_SERVICE_ROLE_KEY` يوضع في Vercel فقط، ولا يظهر في الواجهة.

### 6) قبل التشغيل الفعلي
- شغّلي `supabase/demo/purge_demo.sql` لحذف كل البيانات التجريبية.
- حددي تاريخ بداية البرنامج من «الإعدادات» لتعمل مخططات الأسابيع العشرين.
- راجعي خيارات النسخ الاحتياطي المتاحة في خطة Supabase المستخدمة، وأضيفي نسخة يدوية دورية بالأمر `pg_dump` (أسبوعيًا مثلًا) تُحفظ خارج المنصة.

## الخصوصية والأمان
- رموز الطالبات لا تُخزن نصًا؛ تُخزن بصمة HMAC بمفتاح سري على الخادم.
- كل معلمة ترى طالبات فصولها فقط (سياسات RLS في قاعدة البيانات، لا في الواجهة فقط).
- الزائر يرى مؤشرات إجمالية وأسماء مستعارة فقط عبر دالتين محدودتين.
- سجل تدقيق تلقائي لتعديلات الإعدادات والطالبات والأسئلة والدروس (`audit_log`)، يقرؤه حساب الإدارة.
- تخزين صفحات الكتاب والتسجيلات الصوتية خاص، ويُعرض للطالبة بروابط موقعة مؤقتة.
- يراعي التصميم مبدأ تقليل البيانات في نظام حماية البيانات الشخصية السعودي؛ ويلزم مع ذلك اعتماد المدرسة لسياسة الاحتفاظ بالبيانات وإبلاغ أولياء الأمور.
